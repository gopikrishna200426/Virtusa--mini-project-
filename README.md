## 3. Java — SmartPay Utility Biller 💡💧

A console-based utility billing system that calculates electricity or water bills using a progressive slab method.

### ✨ Features

* Calculates bill based on usage slabs
* Implements interface-based design (`Billable`)
* Validates meter readings
* Generates a digital receipt
* Supports multiple users using loop

### 💡 Billing Logic

* 0–100 units → $1/unit
* 101–300 units → $2/unit
* Above 300 units → $5/unit

### ▶️ How to Run

* Open terminal in Java project folder
* Compile:

  ```bash
  javac src/*.java
  ```
* Run:

  ```bash
  java src.Main
  ```
