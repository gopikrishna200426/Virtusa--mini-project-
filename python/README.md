# 📱 Social Media Content Sanitizer (Python Project)

## 📌 Project Overview

The **Social Media Content Sanitizer** is a Python-based content moderation tool designed to automatically scan and clean user-generated posts.

It helps identify inappropriate language and extract links before content is published, making it ideal for **safe social media platforms**, especially in educational environments.
---
## 🚀 Features
* ✅ Detects and masks banned words (e.g., *bad, toxic, hate*)
* ✅ Extracts all web links from posts
* ✅ Tracks user violations using a dictionary
* ✅ Generates a final moderation report
* ✅ Saves extracted links to a file (`links_found.txt`)
---
## 🧠 Problem Statement
A startup is building a secure social media platform for schools.
Before posts go live, they must be screened for:
* Inappropriate language
* Suspicious or external links
This project solves that problem using Python.
---
